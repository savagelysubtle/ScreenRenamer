# Embed MiniCPM-V Model Locally

## Overview

Transform ScreenRenamer from requiring Ollama to a self-contained application with the MiniCPM-V model embedded locally. Users will download the model from Hugging Face on first setup, allowing the entire app to be packaged and distributed without external dependencies.

## Changes Required

### 1. Create Model Manager Module

Create new [`src/screenrenamer/model_manager.py`](src/screenrenamer/model_manager.py):

- Implement `download_model_from_huggingface()` function to download `openbmb/MiniCPM-V-2_6` from HF Hub
- Store model in `@models/openbmb_MiniCPM-V-2_6/` directory
- Add progress bar using `rich` for download feedback
- Implement `check_model_exists()` to verify model is present
- Handle authentication if needed (HF token for gated models)
- Use `snapshot_download()` from `huggingface_hub` library

### 2. Update Dependencies

Modify [`pyproject.toml`](pyproject.toml):

- Remove `ollama>=0.3.0` dependency
- Add `transformers>=4.40.0` (for model loading)
- Add `torch>=2.0.0` (for inference)
- Add `huggingface-hub>=0.20.0` (for model downloading)
- Add `accelerate>=0.25.0` (for efficient loading)
- Keep existing: `pillow`, `watchdog`, `rich`, `pydantic`, `python-dotenv`

### 3. Update Configuration

Modify [`src/screenrenamer/config.py`](src/screenrenamer/config.py):

- Change `LLMConfig.model_name` default to `"openbmb/MiniCPM-V-2_6"`
- Remove `base_url` field (no longer needed without Ollama)
- Keep `temperature` and `max_tokens` fields
- Update `.env` loading to match new model name

### 4. Enhance Setup Command

Modify [`src/screenrenamer/cli.py`](src/screenrenamer/cli.py):

- Add model download step to `_cmd_setup()`:
- Check if model exists using `model_manager.check_model_exists()`
- If not, prompt user and call `model_manager.download_model_from_huggingface()`
- Show download progress with rich progress bars
- Add `--skip-model-download` flag for advanced users
- Update error messages to guide users to run setup if model missing

### 5. Update Local LLM Processor

Modify [`src/screenrenamer/local_llm_processor.py`](src/screenrenamer/local_llm_processor.py):

- Already loads from `@models` directory ✓
- Update error message in `_ensure_model_loaded()` to guide users: "Model not found. Run 'screenrenamer setup' to download it."
- Ensure model path construction matches the download path from model_manager
- Consider adding 8-bit quantization loading for efficiency

### 6. Create .gitignore

Create [`.gitignore`](.gitignore):

- Add `@models/` to ignore downloaded models (don't commit 8GB model)
- Add `__pycache__/`, `.pyc`, `.env`, `.venv/`
- Add test/coverage artifacts: `htmlcov/`, `.pytest_cache/`, `.coverage`
- Add editor files: `.vscode/`, `.idea/`

### 7. Update README

Modify [`README.md`](README.md):

- Remove all Ollama installation instructions
- Update "Requirements" section: Python 3.14+, ~8GB disk space for model
- Update "Quick Start" to emphasize running `setup` command first
- Explain that first setup downloads model (~8GB, one-time)
- Update architecture diagram to remove Ollama
- Update "LLM Models" section to explain embedded MiniCPM-V
- Add note about model being downloaded to `@models/` on first setup
- Update troubleshooting section to remove Ollama-related issues

### 8. Update .env Template

Update [`.env`](.env):

- Change `SCREENRENAMER_LLM_MODEL` to `openbmb/MiniCPM-V-2_6`
- Remove any Ollama URL references
- Add comment explaining model is loaded locally from `@models/`

## Benefits

- ✅ No Ollama dependency - fully self-contained
- ✅ Clone and run - single package distribution
- ✅ Faster inference - direct model access
- ✅ Portable - works on any system with Python
- ✅ GitHub ready - model downloaded on setup, not committed
